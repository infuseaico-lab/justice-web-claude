# Justice Energy Co. — website

Static, SEO-ready website for Justice Energy Co.: energy-efficiency upgrades and retrofits in Southern California.
The site works on phones, tablets and desktops, and it has no runtime dependencies.

## Pages (11 + utility pages)

| Group | Pages |
| --- | --- |
| Core | Home `/`, About `/about/`, Services `/services/`, Programs `/programs/`, Contact / Request a Consultation `/contact/` |
| Services | `/services/water-heating/`, `/services/hvac-heat-pumps/`, `/services/water-conservation/`, `/services/turf-replacement/`, `/services/led-lighting-retrofits/` |
| Supporting | Privacy Policy `/privacy-policy/` |
| Utility | Form confirmation `/thank-you/` (noindex), `404.html` |

## Project layout

```
build.js                  Static site builder (Node, no dependencies) → dist/
src/site.config.js        Business details, form endpoint, analytics ID  ← edit this first
src/content/services.js   Copy for the five service pages
src/content/programs.js   Program descriptions (drafts awaiting client approval)
src/assets/css|js|img|og  Styles, scripts, illustrations, social share images
src/static/               Files copied to the site root (.htaccess, _headers, _redirects, favicon.ico)
scripts/illustrations.js  Generates the SVG illustrations
scripts/raster.js         Renders social share cards (1200×630) and app icons with Playwright
dist/                     Built site, ready to upload
```

## Build and preview

```bash
node build.js            # writes dist/
npx serve dist           # preview at http://localhost:3000
```

Run the build after changing any file in `src/`. To regenerate artwork, run `npm run images` (needs Playwright with Chromium and ImageMagick).

## Before launch: checklist

1. **Business details**: phone, email, office address and hours are confirmed in `src/site.config.js`. Still to add: the service area (counties or cities), license number and social profile links.
2. **Programs**: confirm each program's official name, description, participation and eligibility wording in `src/content/programs.js`, and set `approved: true`. Add approved logos if supplied.
3. **Privacy policy**: the text is a general draft and needs the client's approval or legal review.
4. **Brand**: the logo is a placeholder mark. Swap in the client logo (header/footer `LOGO` in `build.js`, `favicon.svg`) if one exists.
5. **Redirects**: map old justiceenergyco.com URLs to the new ones in `src/static/_redirects` (Netlify/Cloudflare) or `src/static/.htaccess` (Apache/cPanel).
6. **Form delivery**: see below. Send a test submission after deploying.
7. **Search Console**: verify the domain and submit `https://justiceenergyco.com/sitemap.xml`.

## Consultation form

The form collects name, email, phone, property location, property type, services, program interest and a message. It includes:

- inline field validation with accessible error messages
- spam protection: a honeypot field plus a time trap
- a confirmation page at `/thank-you/`
- pre-selection from links: `/contact/?service=water-heating` or `/contact/?program=socalren`

**Delivery options**

- **Netlify (default):** leave `form.endpoint` empty. Netlify Forms detects the form automatically. In Netlify, go to *Forms → Notifications* and add the client's inbox.
- **Any other host:** create a form at Formspree, Web3Forms or Basin, put its endpoint URL in `form.endpoint`, set the notification email there, and rebuild.

## Deployment

- **Netlify:** connect the repo. `netlify.toml` already sets the build command (`node build.js`) and the publish folder (`dist`).
- **Cloudflare Pages:** build command `node build.js`, output folder `dist`.
- **cPanel / Apache:** run `node build.js` and upload the contents of `dist/` to `public_html`. `.htaccess` handles HTTPS, redirects, caching and the 404 page.

## SEO features

- A unique title, meta description and canonical URL on every page
- Open Graph and Twitter cards with a custom share image for each page
- JSON-LD schema: `HomeAndConstructionBusiness`, `WebSite`, `Service` (per service), `FAQPage`, `BreadcrumbList`, `ItemList`, `AboutPage` and `ContactPage`
- `sitemap.xml`, `robots.txt`, clean URLs, one H1 per page and a logical heading order
- Descriptive alt text on every image, explicit image dimensions to prevent layout shift, lazy loading below the fold and a preloaded hero image
- Accessible navigation: skip link, keyboard-operable menus, visible focus states and support for reduced motion

Search rankings and specific speed scores are not guaranteed.

## Images

All illustrations are original vector artwork generated by `scripts/illustrations.js`. They explain each service and are **not** presented as completed client projects. Replace them with real project photos once the client supplies and approves them.
